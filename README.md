# 🎶 Musicubly

**Musicubly** is a rhythm-based reaction game where you test your speed and precision against waves of incoming cube patterns.  
Rotate your cubes to perfectly match the missing ones before the set collides — but stay sharp, because everything syncs with the **beat of the music**!

The game features a custom **beat detection algorithm** that drives both the gameplay and the beat visualization, making every session feel dynamic and musical.  

---

## 🕹️ Gameplay

- **Reaction challenge**: Quickly rotate your cubes to fit the incoming sets.  
- **Wave system**: Survive increasingly fast cube waves.  
- **Beat detection**: Gameplay adapts to the rhythm of the track.  
- **Beat visualization**: Watch the rhythm come alive visually as you play.  

---

## 🎮 Controls

| Key | Action |
|-----|---------|
| `Space` | Rotate cubes |
| `Esc` | Pause |
